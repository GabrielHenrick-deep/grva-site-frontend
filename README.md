## 💻 Sobre o Projeto

Mergulhei de cabeça no desenvolvimento e construí uma aplicação completa do zero. No front-end, optei pela robustez e reatividade do React com TypeScript, estilizando a interface com Tailwind CSS para um design moderno e responsivo.

Para o back-end, a escolha foi o ecossistema Laravel com PHP 8, garantindo performance e uma base sólida para futuras expansões.
​O resultado é uma plataforma dinâmica que não apenas expõe o trabalho incrível do Grupo de Realidade Virtual e Aumentada - GRVA, mas também serve como um canal direto para atrair novos talentos e oportunidades de negócio.

​Foi uma jornada de muito aprendizado e fico orgulhoso de contribuir para a missão do laboratório. Confira o projeto e me diga o que achou!
